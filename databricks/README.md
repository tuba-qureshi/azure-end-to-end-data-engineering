Azure Databricks – Data Transformation

Overview

Azure Databricks was used as part of the Azure End-to-End Data Engineering project to work with data processing and transformation in the data engineering workflow.

This component focuses on the Silver layer, where data processing is performed using Apache Spark and PySpark.

Databricks Notebook

Silver Layer – "silver_layer"

The Silver layer notebook was created for data processing and transformation as part of the project's data pipeline.

The notebook source code is included in this repository to preserve the implementation and provide a reference for the processing logic.
